# QH packed runtime — first full-model preparation milestone

2026-11-28 user approved moving beyond matrix optimization. Main objective is the minimum stable block swap at up to 1 MP on RTX 4070 Ti 12GB, rank32; no tests above1MP. Start with QH2 (2.25 bits), QH3 (3.25 bits), QH-mix25 (<=2.5 bits). All 224 eligible projections; original Raw BF16 supplies noneligible weights via existing native_runner.compact_loader, with existing INT8 fallback where applicable. Not a self-contained checkpoint yet. No production changes, no further matrix tuning.

QH runtime format: concatenated row-major bit-plane Q2 and Q3 streams (original row order within each precision), BF16 scales in original row order, and packed precision mask last (mixed only). Odd code levels -3,-1,1,3 or -7,-5,-3,-1,1,3,5,7, exact BF16 product as in QH-4B. Fixed group64 and H64. Q3 count derived from shape/2.5 cap including mask. Spec contains only codec/shape/group/count, identical for corresponding projections in all 28 blocks, per-block mask inside payload. This preserves existing classic swap loader's identical layout check without modifying swap engine. Runtime derives fixed-size row indices from cumulative mask, reconstructs only 128 rows per tile, rotates input once, backward accumulates FP32 across BF16 tile products then applies H64 and casts back. Frozen custom autograd saves packed bytes only, not decoded weights; adapter remains in original coordinates. No fused kernels or speed claims; prior Q6 eager runtime was very slow. Mixed gathers both code streams for each tile and may be even slower than uniform; optimize after measuring. Actual CUDA swap correctness, transient peaks, full Krea2 training and adapter export/reload pending.

Preparation script qh_prepare.py verifies original Raw hash, complete QH-4B report, all224 shapes/dtypes, identical swap layout, packed bytes and archive roundtrip. It imports exact hash-verified existing task-targeted 2.5-bit archives for blocks.0.attn.wk.weight, blocks.14.attn.wk.weight, blocks.0.mlp.up.weight. The other221 matrices use weight-only ranking (exact isolated squared weight-error improvement). Do NOT label this model fully task-calibrated. Full uniform Q2 and Q3 use same four-step odd-code initializer as prior experiments. Output three reusable archives and prepare-report.json, fresh directory required. No recalibration or dev-based row selection, no extra math experiments. CPU conversion, large checkpoint reads and temporary disk usage may be substantial; no runtime estimate measured. Prior eligible INT8 size 12.16GB implies roughly12.2GB aggregate packed payload for all three archives; noneligible Raw still required.
