# Experiment 5B — causal block identity
Five epochs, 145 optimizer updates, seed 42, LR 0.00045, same 29 training / 3 holdout dataset, Muon and strict deterministic settings from 5A. Test Mode queues six arms in order: unrestricted, adaptive gradient, count-matched random, exact mask replay, block 26 alone, block 13 alone. The four interventions load ONLY the completed adaptive source in the current queue's report. They keep the same warmup and full-block probes, bypass adaptive scoring, and use source probe counts/identities or the block-26 suspension schedule. B5 and B6 have equal omission timing/count; neither is required to match B2's overall count. No optimizer or learning-rate changes. Source failure prevents dependent arms from proceeding.
All arms log raw factor fingerprints at every step, actual gradient-bearing masks, per-factor probe telemetry, raw and EMA validation each epoch, and unchanged preview prompts. Full FP32 raw/EMA checkpoints at each epoch retained locally (~26 GB across six arms, excluding ordinary saves/states). The ZIP still excludes weights. Report validates all expected masks and records source-vs-control first hash and mask differences. Exact replay must match B2 at every step; if not, investigate before claiming causality. Also compare B5/B6 directly, including their shared prefix. Hashes establish adapter-factor equality, not optimizer-state equality. Determinism established only for 58 steps in 5A; recheck full horizon. The single seed is exploratory, not independent replication. Production defaults unchanged.
