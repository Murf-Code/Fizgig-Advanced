# Selective finalist LR compensation pilot

User approved eight fresh six-epoch arms after the effective-score GPU pilot and visual review. PoLoRA and LoRA-TSD each run Existing and Astra, compensation off/on. Seed 42, original 15-image dataset (13 training / 2 holdout), rank/alpha 32, native INT8, 22 swaps, 0.25 MP, same two fixed sample prompts and sample seed, baseline and every epoch, no adaptive or per-image LR. 78 updates per arm, 624 total. Fresh off controls; unrestricted reference available in prior six-arm report, not repeated here. No selector changes.

Native learning-rate multiplier on active steps: min(cap, sqrt(28/active)). PoLoRA cap 1.5, LR .02; TSD cap 1.25, LR .005. Full probes multiplier one. These limits are experimental, not optimal. PoLoRA consumes group LR in rho before native factor update; TSD consumes group LR before native factor update and clipping. Preserve magnitude 3, native cap (.1 times magnitude), optimizer local state and scheduler LR. The TSD cap is a linearized update norm bound, not an exact finite product displacement bound. No change to production compensation allowlist or toggle. Exact native class and adapter coverage checks inherited from prior harness. Restore rates in finally; no rollback on failed optimizer step. TSD log_every=1 for all four TSD arms so cap counts are measured every update, not extrapolated. Logging overhead is shared within optimizer, not a clean throughput measurement.

Record applied rates, restoration, effective movement, cap saturation, masks, same-probe alignment diagnostics, input and initial fingerprints, inactive-state audit, reactivation movement, validation and fixed samples. Report compensated arms paired to own off selector; off arms to Existing off, preserving cross-selector comparability. A matched input hash is not proof of deterministic trajectory. No claim that movement parity or higher learning rate is better. Keep the two finalists regardless of single-seed ranking; evaluate samples and cap saturation before any further calibration or production integration.
