# 6C.2k-C dual precision allocation pilot

Run on the same 15-image dataset and caches. Test Mode queues one unrestricted epoch, rank/alpha 32, Muon .00045, INT8, 22 swaps, seed 42, at update 8. One native proposal, five allocations: uniform; block 26 half multiplier; block 13 half multiplier; lowest gradient RMS half multiplier; largest native FP32 block displacement / gradient RMS half multiplier (floor 1e-12). All other block multipliers start at one; bounded common scaling matches realized FP32 movement. Ratio is exploratory and gauge-/scale-dependent, not evidence of utility. Exact duplicate multiplier vectors are reported as aliases. Decay-only, quarter, half and full native update are positive/negative sensitivity controls, not matched candidates.

Native W8A8 and weight-only INT8 evaluate the same endpoints, each with independent parent/base references, complete held-out panel, repeated parent, after-base, after-each-candidate restoration, reversed decay replay and final native restoration. Records actual FP32 and BF16-cast geometry (not BF16 matmul output), exact endpoint hashes, per-case signed loss metrics, base drift and prediction displacement. Progress messages at every evaluation panel. Retains partial reports on failure. The terminal ZIP includes movement-dual.json. One parent, target-only, no near/far preservation panel, no inference of statistical superiority. Weight-only changes numerical instrument and is not FP32 ground truth. No longer-horizon confirmation or production changes. Historical block reversion is separate.

Local CPU research suite: 108 checks passed (three new dual-core tests using mocked forward/precision context, including alias selection and restoration failure). Queue wiring/export assertions added but not executed locally; GPU path unverified.
